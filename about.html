About this project

This microsite teaches beginners the basics of 3D animation with Blender. It was built for IM22103 Multimedia Web Programming.

Objectives

  • Explain Blender fundamentals clearly with step-by-step lessons.
  • Use interactive features: 3D preview, quizzes and a video gallery.
  • Work on desktop, tablet and mobile, with dark mode and keyboard access.
